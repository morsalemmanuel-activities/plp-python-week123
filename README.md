# Week 5 Assignment: Password Generator & Your Own Module

## Project Overview
This repository contains solutions for the Week 5 assignment focusing on importing standard Python libraries and architecting custom local modules.

## File Breakdown
* `password_generator.py`: Generates custom alphanumeric string sequences of variable lengths dynamically using `random` and `string` features.
* `helpers.py`: Custom module containing calculation scaling logic and personalized welcome messages.
* `main.py`: The application engine that imports our local `helpers` workspace to run the script.
